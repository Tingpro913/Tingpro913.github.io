# 需求文档

## 1. 应用概述

### 1.1 应用名称

LT个人主页

### 1.2 应用描述

一个简约清爽的个人主页网站,用于展示LT的个人信息和职业背景,并通过数字分身聊天区与访客进行互动交流。主要面向潜在客户和面试官,帮助他们快速了解LT的专业能力和工作方向。网站采用响应式设计,支持网页端和移动端访问。

## 2. 用户与使用场景

### 2.1 目标用户

- 潜在客户:希望了解LT的专业能力和服务内容
- 面试官:希望了解LT的职业背景和工作经验

### 2.2 核心使用场景

- 访客通过链接访问个人主页,浏览LT的基本信息和职业介绍
- 访客通过数字分身聊天区提问,获取关于LT的更多信息
- 访客在网页端或移动端访问主页,获得良好的浏览体验

## 3. 页面结构与功能说明

### 3.1 页面结构

```
个人主页
├── 头部区域
│   ├── 头像
│   ├── 名字
│   └── 一句话介绍
├── 个人信息展示区
│   ├── 我现在主要在做
│   ├── 我的兴趣
│   └── 我比较有记忆点的特点
└── 数字分身聊天区
    ├── 聊天记录展示
    ├── 输入框
    └── 发送按钮
```

### 3.2 功能说明

#### 3.2.1 头部区域

- 展示默认头像占位图
- 展示名字:LT
- 展示一句话介绍:一个正在学习用AI做产品和流程的跨国员工管理HR

#### 3.2.2 个人信息展示区

- 展示「我现在主要在做」:整理国际派遣流程、跨国员工管理和探索AI方向
- 展示「我的兴趣」:AI应用、跨国员工流动
- 展示「我比较有记忆点的特点」:
  - 喜欢探索未知和尝试新东西
  - 多年跨国员工管理HR经验
  - 能和多云背景团队高效对接
  - 具备自驱力、服务意识

#### 3.2.3 数字分身聊天区

- 访客在输入框中输入问题
- 点击发送按钮提交问题
- 聊天记录展示访客提问和数字分身回复
- 数字分身基于以下背景信息回答问题:
  - 职业或身份:跨国员工流动HR
  - 最近在做的事:搭自己的个人主页,整理经验,利用AI工具沉淀产品
  - 擅长或关心的方向:内容表达、AI应用、知识整理、流程重塑
  - 常见问题参考:你现在在做什么?你能解决什么问题?怎么联系你?
- 使用MiniMax大模型生成回复内容

## 4. 业务规则与逻辑

### 4.1 数字分身对话规则

- 访客提交问题后,调用MiniMax大模型生成回复
- 数字分身回复需基于LT的背景信息,保持角色一致性
- 聊天记录按时间顺序展示,最新消息在底部

### 4.2 响应式设计规则

- 页面采用响应式设计,自适应网页端和移动端不同屏幕尺寸
- 网页端访问时,各模块横向或纵向合理布局
- 移动端访问时,各模块垂直排列,确保内容可读性和操作便捷性

### 4.3 视觉风格规则

- 整体配色以深蓝色和白色为主
- 页面布局简约清爽,信息层次清晰
- 避免过多装饰元素,突出关键信息
- 保持科技感

## 5. 异常与边界情况

| 场景                       | 处理方式                               |
| -------------------------- | -------------------------------------- |
| 访客未输入内容直接点击发送 | 不触发提交,提示「请输入问题」         |
| 数字分身回复生成失败       | 显示「抱歉,暂时无法回答,请稍后再试」 |
| 访客输入内容过长           | 限制输入框字符数量(建议500字以内)    |
| 聊天记录过多               | 仅展示最近20条对话记录                 |

## 6. 验收标准

1. 访客在网页端打开个人主页,看到头像、名字、一句话介绍和个人信息展示区
2. 访客在移动端打开个人主页,页面布局自适应,内容清晰可读
3. 访客在数字分身聊天区输入问题「你现在在做什么?」
4. 点击发送按钮,数字分身基于LT的背景信息通过MiniMax大模型生成回复并展示在聊天记录中
